# تشريح السيارة 3D · Car Anatomy 3D

مجسّم سيارة سيدان (على طراز BMW) ثلاثي الأبعاد بيشتغل بالمتصفح. اكبس على أي قطعة لتشوف:
اسمها بالعربي والإنجليزي، وين موجودة، شو وظيفتها، شو بيصير إذا خربت، وقدّيش العطل خطير.

- 105 قطعة مقسّمة على 16 نظام (المحرك، التيربو، الوقود، العادم، التبريد، نقل الحركة، الفرامل، التعليق، التوجيه، العجلات، الكهربا، التكييف، الأمان، المقصورة، الهيكل، الشاسيه).
- 3 أوضاع للهيكل: شفّاف، كامل، بدون هيكل.
- زر «شغّل المحرك» بيحرّك البساتم والكرنك والكامات والمروحة والعجلات.
- زر «اسمع» بيلفظلك الاسم بالإنجليزي.

## How to open

Open `index.html` in any modern browser (Brave, Chrome, Edge, Firefox). It needs an internet
connection the first time because it loads three.js 0.160.0 from jsDelivr.

The descriptions are simplified for learning. They are general automotive knowledge, not a repair
manual — always check your car's own service manual before working on it.
