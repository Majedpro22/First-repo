# تشريح السيارة 3D · Car Anatomy 3D

مجسّم سيدان (على طراز BMW) ثلاثي الأبعاد بيشتغل بالمتصفح. اكبس على أي قطعة وبتشوف:
اسمها بالعربي والإنجليزي، وين موجودة، شو وظيفتها، شو بيصير إذا خربت، وقدّيش العطل خطير،
**وأنيميشن بيورجيك كيف بتشتغل** (مثلاً: الانفجار والبساتم، الهوا والتيربو، زيت الفرامل والديسكات السخنة،
الماي السخن والبارد بالرديتر، الأبواب والكبوت بينفتحوا، الدركسيون، التعليق، الإيرباغ...).

- 117 قطعة مقسّمة على 16 نظام، منهم قطع العجلة بالتفصيل: براغي العجل، بلف الهوا، حسّاس ABS، حامل العجلة، الكرات، صاج الديسك، خرطوم الفرامل، بساتم الكاليبر، حسّاس تآكل الفحمات، بطانة الرفرف، قاعدة المساعد، وروابط عمود التوازن.
- زر «ألوان حقيقية / ألوان الأنظمة»: إمّا كل قطعة بلون مادّتها (ألمنيوم، حديد، كاوتشوك...) أو كل نظام بلونه.
- القطعة اللي بتختارها بيصير حواليها إطار مضوّي واسمها فوقها، وباقي القطع بتخفّ.
- 3 أوضاع للهيكل: شفّاف، كامل، بدون هيكل.
- زر «شغّل المحرك»، وزر «اسمع» بيلفظلك الاسم بالإنجليزي.

## How to open

Open `index.html` in a modern browser (Brave, Chrome, Edge, Firefox) with WebGL2. It needs an
internet connection because it loads three.js 0.160.0 from jsDelivr.

The descriptions are simplified for learning. They are general automotive knowledge, not a repair
manual: always check your car's own service manual before working on it.
